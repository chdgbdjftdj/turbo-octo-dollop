# Веб-приложение "Учёт сотрудников"

## Архитектура системы
- **Бэкенд:** Python + Flask
- **База данных:** SQLite с реляционными связями
- **Фронтенд:** HTML + CSS + Jinja2 шаблоны
- **Веб-сервер:** Flask development server

## Функциональность
- Просмотр списка сотрудников
- Группировка по отделам
- Отображение зарплат и дат приёма
- Адаптивный веб-интерфейс

## Структура базы данных
- **Таблица departments:** отделы компании
- **Таблица employees:** сотрудники с внешним ключом к отделам

## Запуск приложения
1. `python database.py`  # создание БД
2. `python app.py`       # запуск сервера  
3. Открыть http://localhost:5000
